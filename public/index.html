SYSTEM DESIGN

Built for control.

A bounded single-agent planner–executor with a deterministic evidence gate. No multi-agent framework, unbounded loops or autonomous write actions.

↳ One recovery step when unique evidence is insufficient. Optional LLM selects exact evidence spans and proposes separately labeled source-linked analysis; it never executes tools.

Execution budget

Up to 3 initial tool calls in parallel, one recovery step, 2 attempts per step, one optional model request.

Evidence integrity

Every finding links to a retained source ID. Model-selected passages must match exact text; this does not prove source accuracy or entailment.

Safety boundary

Fixed read-only provider endpoints, bounded inputs and response bodies, heuristic injection filtering, no arbitrary URL retrieval.

Production tradeoffs

Snippet-based research, lexical relevance, heuristic confidence, no durable state or distributed rate limiter. Public demo is credential-free; live access is gated by default.
